# 컷씬 자막 싱크 편집기

TR2 컷씬(CUT1~CUT3)의 대사 자막을 음성에 맞추는 도구입니다. 음성 파형을 보면서 대사가 시작되는 시각을 고치고, 고친 결과를 소스에 바로 반영합니다.

| 파일 | 역할 |
|---|---|
| `subtitle_sync.html` | 편집기 화면 |
| `serve.py` | 편집기를 띄우고, 자막을 소스에서 읽고 소스에 다시 쓰는 로컬 서버 |

## 준비

- Python 3
- 한국어 자막을 반영하려면 Pillow (`pip3 install Pillow`)
- 한국어 대사에 새 글자가 생길 때 그 글자를 그릴 폰트. 기존 글자와 같은 모양이 되려면 맑은 고딕(`malgun.ttf`)이 필요합니다. `serve.py`는 아래 순서로 폰트를 찾고, 없으면 `--font`로 지정해야 합니다.
  `C:/Windows/Fonts`, `/Library/Fonts`, `~/Library/Fonts`의 `malgun.ttf` → Apple SD Gothic Neo → 나눔고딕

## 실행

저장소 루트에서 실행합니다. `--music`에 게임의 `music` 폴더를 주면 컷씬을 고를 때 음성이 자동으로 열립니다.

```bash
python3 src/tools/subtitles/serve.py --music ~/Downloads/TR2/music
```

브라우저에서 `http://127.0.0.1:8765/`가 열립니다. 서버는 `Ctrl+C`로 끕니다.

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--music <폴더>` | 없음 | 게임의 `music` 폴더 (`Track02.ogg` …). 없으면 음성 파일을 직접 고릅니다. |
| `--font <파일>` | 자동 탐색 | 새 한글 글자를 그릴 폰트 |
| `--port <번호>` | `8765` | 서버 포트 |
| `--src <폴더>` | 저장소의 `src` | 다른 작업 사본의 `src`에 반영할 때 |
| `--no-browser` | | 브라우저를 자동으로 열지 않음 |

## 사용 순서

1. **컷씬과 언어를 고릅니다.** 자막은 서버가 소스에서 읽어 오므로 항상 최신입니다.

   | 컷씬 | 장면 | 음성 파일 |
   |---|---|---|
   | CUT1 | 만리장성 이후 | `music/Track02.ogg` |
   | CUT2 | 오페라 극장 이후 | `music/Track03.ogg` |
   | CUT3 | 다이빙 구역 마지막, 죽어가는 수도승 | `music/Track04.ogg` |

2. **시각을 맞춥니다.** 재생하면서 게임 화면처럼 나오는 자막과 파형을 봅니다.
   - 대사가 시작되는 순간 **M**을 누르면 다음 대사의 시작 시각이 지금 위치로 정해집니다. 처음부터 재생하며 M을 차례로 누르면 한 번에 맞출 수 있습니다.
   - 타임라인의 세로 경계선을 끌어 옮길 수 있습니다.
   - 대사 목록에서 −0.1 / +0.1, "지금"(현재 위치로), ▶(그 대사 직전부터 재생)을 쓰거나 숫자를 직접 고칩니다.
   - "선택 이후 전체 이동"은 선택한 줄부터 끝까지를 한꺼번에 밀거나 당깁니다.
   - 단축키: Space 재생/정지, ←/→ 0.1초 이동 (Shift와 함께 1초)

3. **소스에 반영합니다.** 맨 아래 "소스에 반영"을 누르면 다음을 차례로 처리합니다.
   - 영어: `src/lang.h`의 `STR_TR2_SUBS` 안 `/* CUTn */` 블록을 바꿉니다.
   - 한국어: `src/lang/ko.h`의 `#if 0` 안 UTF-8 원문 블록을 바꾼 다음, `src/tools/glyphs/ko_glyphs.py`로 실제 빌드되는 글리프 문자열과 글리프 이미지(`glyph_ko.h`, `glyph_ko.bmp`, `glyph_ko.txt`)를 다시 만듭니다.
   - "빌드까지"를 켜면 이어서 macOS 빌드(`src/platform/osx/build.sh`, Release와 Debug)를 실행합니다. 배포(앱 복사)는 하지 않습니다.

   시작 시각이 앞 대사보다 빠른 줄이 있으면 반영하지 않습니다. 편집 중인 내용은 브라우저에 저장되고, 반영하고 나면 지워집니다.

## 자막 형식

컷씬 하나의 자막은 `"[시작 ms]대사"` 문자열이 이어진 구조입니다.

```c
    /* CUT3 */ ,
    "[3448]아... 당신은 그 패거리들@중 하나가 아니군요."
    "[5593]하지만 당신은 수도사군요."
    ...
    "[27107]"
```

- 시각은 음성 트랙이 시작된 때부터의 밀리초입니다. 한 대사는 다음 줄의 시각까지 표시됩니다.
- 대사 없이 `"[ms]"`만 있는 줄은 앞 대사가 끝나는 지점(빈 구간)입니다.
- `@`는 화면의 줄바꿈입니다. 대사 안에 `[`, `]`는 쓸 수 없습니다.
- `lang.h`는 매크로라 줄 끝에 `\`가 붙고, `ko.h`는 배열이라 붙지 않습니다. 반영할 때 각 파일의 형식에 맞춰 씁니다.

## 서버 없이 쓰기

`subtitle_sync.html`을 브라우저로 바로 열어도 편집과 코드 복사는 됩니다. 이때는 다음처럼 동작합니다.

- 자막은 파일에 내장된 사본을 씁니다. 최신 자막은 "자막 소스"로 `src/lang.h`나 `src/lang/ko.h`를 열어 읽습니다.
- 음성 파일은 직접 고릅니다.
- "소스에 반영" 대신 "코드 복사"로 블록을 복사해 붙여 넣습니다. 한국어는 붙여 넣은 뒤 `ko_glyphs.py`를 직접 실행해야 게임에 반영됩니다.

```bash
python3 src/tools/glyphs/ko_glyphs.py src/lang /Library/Fonts/malgun.ttf
```

## 주의

- 컷씬을 확인하려고 `data/cut3.TR2`처럼 컷씬 레벨을 바로 실행하면, 컷씬이 끝날 때 다음 레벨로 넘어가며 자동 저장됩니다. 이때 기존 체크포인트 세이브가 지워질 수 있으니, 확인만 할 때는 컷씬이 끝나기 전에 종료하거나 세이브 파일(`~/Library/Application Support/OpenLara/tr2/savegame.dat`)을 미리 백업하세요.
- 게임은 자막 설정이 켜져 있고 언어가 맞을 때만 자막을 보여 줍니다.
